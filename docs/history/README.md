# Historical adapter references

This directory preserves retired FreeCAD instructions and their related references.
The archived files retain their original content and recorded code hashes.
They are evidence of earlier designs, not instructions for the current MCP.
The current service has no FreeCAD proxy.

The archive includes the inline adapters, execution guide, tooling contract, model contract, and edge-treatment references.
The metric-thread table remains with its archived caller so their relative link stays valid.
Four small link files connect historical links to the current maintained guides.

Use the current [skill](../../skills/drawing2cad/SKILL.md) for permitted tool sequences and profile boundaries.
The skill does not load this archive. Do not copy these files into the installed skill package.
