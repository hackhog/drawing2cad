Sample parts are organized into different folders.
Each folder contains a 2D PDF drawing as the input format.
The STEP file can be used to compare the results.
.prt files (native Siemens NX CAD format) are also included.
These files can be used, but are not required.

__________________________________________________________________

Beispielteile sind in verschiedene Ordner aufgeteilt.
In jedem Ordner befindet sich eine 2D-PDF-Zeichnung als Inputformat.
Die STEP-Datei kann zum vergleich der Ergebnisse genutzt werden.
Ebenfalls vorhanden sind .prt-Files (natives Siemens NX CAD Format).
Diese Files können verwendet werden, müssen jedoch nicht.
